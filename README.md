**# 🤖 Web Download AI Agent**



**An AI-powered agent that searches any website and downloads files**

**(.zip, .rar, .exe, .msi, .srt, ...) using natural language.**



**Built with the OpenAI SDK and works with any OpenAI-compatible API**

**(OpenAI, OpenRouter, Groq, SnapTech, local LLMs, ...).**



**## ✨ Features**



**- 🔍 Natural language interface (Persian / English)**

**- 🌐 Works with ANY website the user names**

**- 🧩 Multi-step reasoning via tool calling**

**- 📦 Direct-file downloads with automatic filename detection**

**- 🗜️ Auto-extract for `.zip` archives**

**- 📝 File-based logging (`downloads/agent.log`)**

**- 🔒 Size limit per download (default 500 MB)**

**- 🔌 Provider-agnostic (OpenAI-compatible endpoints)**
